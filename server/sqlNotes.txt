// What is SQL 
SQL = Structured Query Language
SQL is:
A language used to store, read, update, delete
Data stored in relational databases

SQL is not a databases 
MySQL/PostgreSQL/Oracle are databases that understand SQL
--------------------------------------------
Relational Databse - what does it mean?
A relational database stores data in :
Tables
Connected via relationships

Example
Instead of one big JSON:
{
    user:{
        "name":"Suhail"
        "orders":[...]
    }
}

SQL does:
One table for users
One table for orders
Linked using keys

This avoids duplication inconsistency messy updates

---------------------------------------------------
KEYS (VERY IMP)

PRIMARY KEY 
Uniquely identifies a row 
Cannot be NULL 
Cannot repeat
ex: id INT PRIMARY KEY 
MongoDB equivalent:
_id

FOREIGN KEY 
Connects two Tables
Enforces relationships 
orders.user_id -> users.id 
This is what makes SQL relational
----------------------------------------------------
RELATIONSHIPS TYPES
1.One-to-One 
. User <-> Profile
user.id -> profile.user_id

2.One-to-Many(Most Common)
. User -> Orders
users.id → orders.user_id

3.Many-to-Many
.Students <-> Courses
Solved using junction table
student_courses
(student_id, course_id)
-------------------------------------------------
CONSTRAINTS (DATA SAFETY RULES)
Constraints protect your data

Constraint	Meaning
NOT NULL	Value required
UNIQUE	    No duplicates
DEFAULT	    Auto value
CHECK	    Custom rule
FOREIGN KEY	Relationship enforcement
Example:
email VARCHAR(100) UNIQUE NOT NULL
---------------------------------------------------
ACID PROPERTIES (WHY SQL IS TRUSTED)
SQL databases follow ACID

Property	Meaning
Atomicity	All or nothing
Consistency	Rules always valid
Isolation	Transactions don’t clash
Durability	Data never lost

This is why banking apps use SQL

MongoDB supports this partially, SQL does it by design
---------------------------------------------------
TRANSACTIONS (THEORY)
A transaction = multiple steps treated as one unit

Example:

1.Deduct money
2.Add order
If step 2 fails → step 1 is undone

BEGIN
step 1
step 2
COMMIT / ROLLBACK
