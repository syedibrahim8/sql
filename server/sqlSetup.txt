Core SQL Concepts (VI)

SHOW DATABASES;              -> shows all databases.
CREATE DATABASE <dbname>;    -> creates a new database.
USE <dbname>;                -> uses selected database
SELECT DATABASE();           -> shows database you are inside or using
DROP DATABASE <dbname>       -> deletes a database.

// CREATE TABLES
ex:
CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL
);

SHOW TABLES;               -> Shows all the tables in the database.
SELECT * FROM <table name> -> selects all the data from the given tableName.
INSERT INTO <table name> VALUES (2,"RAYYAN","rayyan@gmail.com"); -> inserting values in tables
UPDATE <table name> SET <key> = <changing value> WHERE <poiniting key> = <vale>; -> updating specific value
DELETE FROM <table name> WHERE <key> = <value>; -> deletes a specific row from given condition meet


DESCRIBE <tablename>;      -> display the structure or schema of a database table.
